CRACKER NOTES

Nothing was cracked in the making of this release. The only thing that got hacked is a perfectly good synthwave sunset.

It started as a vertical music video. Some people said it was “just AI”. It is not. The music and the sprites are AI-made; the picture is a program: GLSL shaders, an ASCII post-pass, raymarched glass and a type engine that slams on the real kick drums. This exe is that program, running live, synced to the audio clock, on whatever display you have.

F.A.Q.

> is it a virus?

No. It is an unsigned PyInstaller exe, which some antivirus tools and Windows SmartScreen flag by reflex. Every line of source is in the repo, the build is a single script, and the release page lists the SHA-256 of the exe. Don't trust it? Build it yourself, or run it from source.

> what do I need?

Windows 10/11 and a GPU with OpenGL 3.3 (anything from the last decade). It adapts to your screen: 16:9, ultrawide, even a rotated monitor. Slow GPU? Press - or start it with --scale 0.5.

> controls?

Esc quit · Space pause · ←→ seek ±10s · R restart · F fullscreen · F12 screenshot · -= render scale. In the credits press 1-4 to open the links.

> can I render it to a video?

Yes. R00T_ACCS.exe --export out.mp4 --res 1920x1080 (needs ffmpeg on PATH). Use --res 1080x1920 for the vertical cut. The picture is a pure function of time, so exports are frame-exact.
